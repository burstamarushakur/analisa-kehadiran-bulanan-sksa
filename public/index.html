TETAPAN KOMPUTER GURU

Sambungan & simpanan

Sediakan sekali pada browser yang digunakan untuk IDME.

01

Pasang extension

  1. Ekstrak ZIP sistem ini. Buka chrome://extensions.
  2. Aktifkan Developer mode, pilih Load unpacked dan folder extension.
  3. Buka extension SKSA. Masukkan IC yang sama dan password IDME.
  4. Tandakan simpan password untuk auto login. Password disimpan pada browser ini.
02

Padankan dengan webapp

Salin pautan ini ke ruang pautan webapp dalam extension. Tekan Simpan tetapan dan benarkan akses.

Kemudian refresh webapp untuk menyambung.

Sesi IDME yang masih aktif boleh digunakan terus. Jika sesi tamat, extension menggunakan password yang disimpan.

03

Tempat simpan laporan

Menyemak sambungan database…

Simpan JSON sebagai salinan jika menggunakan simpanan browser.

04

Import & laporan

JSON yang dimuat turun daripada extension boleh diimport semula. Import bulan yang sama mengemas kini rekod apabila data lebih baharu.

PDF mengikut tarikh, jumlah asal, warna cuti dan tanda kosong dalam IDME. Januari yang bermula pada 11 haribulan dikekalkan.
